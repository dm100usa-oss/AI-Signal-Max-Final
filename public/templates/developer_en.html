Basic Technical Requirements

To increase the website's chances of appearing in AI platform answers, the following basic principles must be followed:

  • Security: HTTPS on all pages, valid SSL certificate, automatic redirect from HTTP, HSTS enabled.
  • Crawler accessibility: correct robots.txt with explicit permission for AI bots (GPTBot, ClaudeBot, Google-Extended), up-to-date sitemap.xml.
  • Performance: server response time under 1.5 seconds, caching, Gzip/Brotli compression, image optimization.
  • Metadata: unique title and meta description on each page, correct canonical links, no conflicting indexing directives.
  • Structured data: JSON-LD Schema.org markup for precise identification of business type and content.
  • Mobile responsiveness: viewport meta tag present, correct display on mobile devices.
  • Content quality: alt attributes on all images, correct 404 error handling, Open Graph tags for correct link display.
  • Content accessibility without JS: important content must be available in the page source without JavaScript rendering — AI crawlers often read pages without executing scripts.
